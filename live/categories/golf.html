Topic inclusion and data notes

Golf tournament and player markets matched by golf, PGA, LPGA, Masters, and related terms. Classification is based on the event title, event category/ticker, and market title/ticker returned by the official API. Search coverage is limited to the first 800 open events returned per refresh; this page does not assert that it is a complete census of every Kalshi market. Open-interest value is calculated from open_interest_fp × notional_value_dollars, defined by the API as one contract’s settlement value; this is not traded-dollar volume. Each row links to its official demo market API response.

Quotes are snapshots from REST polling and may lag. A missing value is not estimated; the cell is flagged UNVERIFIED. For complete orderbook depth and real-time updates, see the official API guides linked from the executive summary.
