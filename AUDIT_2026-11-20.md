## Corrections made

1. `EXECUTIVE_SUMMARY.md` now states that the side which wins (YES on a YES result, NO on a NO result) receives $1 per contract; the losing side receives no payout. The prior shorthand could incorrectly imply NO never pays.
2. `docs/summary.html` now reports the official candle intervals as 1, 60, or 1440 **minutes**. The chart's “seconds / minutes / hours” controls are display windows, not API candle granularities.
3. `tools/rendercheck.mjs` now stubs `window.fetch` as an offline miss, so the runtime checker exercises inline snapshot rendering without requiring a browser fetch implementation or contacting the network.
4. `scripts/collect.mjs` now defaults to the demo API and validates that the base URL is HTTPS, has one of the documented demo hosts, uses `/trade-api/v2`, and has no custom port, credentials, query, or fragment. A test rejects production and arbitrary hosts. The workflow cache namespace is demo-specific.
