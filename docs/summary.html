Executive summary

Plain-language overview of what this site is, where every number comes from, and what is deliberately left blank. Mirrors EXECUTIVE_SUMMARY.md in the repo root.

What this is

  • A live dashboard for the highest-dollar-volume Kalshi demo events, limited to five topics: gas prices, elections, culture, crypto, golf.
  • Feeds refresh every ~15 minutes via GitHub Actions (.github/workflows/collector.yml); the page itself polls the published JSON every 20s.
  • Alerts fire on any contract-price swing ≥ $0.10 in either direction, shown as two scrolling chats: all events and a high-ROI model filter.
  • Markets are tracked through resolution — every settled market shows its official YES/NO outcome.
  • An automated paper-trading engine executes simulated strategies, tracks equity, and reports results by strategy and by trade type.

Where the data comes from (official only)

  • REST base: external-api.demo.kalshi.com/trade-api/v2 ↗ (docs ↗)
  • WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (docs ↗) — requires API-key handshake, so the live layer polls REST instead (flagged)
  • Series → topic mapping: Get Series List ↗ (category is exact/case-sensitive)
  • Charts: candlesticks ↗ · Depth: order book ↗ · Trades: trades ↗
  • Fees: official fee schedule PDF (eff. 2026-07-07) ↗
  • Settlement: market settlement ↗

Verification policy (strict)

  • Every table row carries a link to its official source (API endpoint and/or docs page).
  • If a value cannot be confirmed from an official source it is left blank and marked unverified — never inferred, never filled in.
  • Blanks sort to the bottom of every table so they can't masquerade as values.
  • All unverified/irregular items are published on the Flagged for Review page (current count: …).
  • Headlines attached to swings are candidate catalysts by time proximity only — explicitly not claimed as causes; blank when none verify.

Trading model (transparent by design)

  • Mode: simulated paper account — no credentials exist in this environment (FL-01), so no orders are ever sent.
  • Fills: taker against the real demo order book; fee = ceil(0.07 × contracts × price × (1−price)), reproduced against all 42 rows of the official table by an automated test.
  • Strategies: momentum (follow ≥$0.10), reversal (fade it), and a high-ROI filter that only trades when 30% × swing − fee − spread ≥ $0.02 per contract. The 30% reversion share is an explicit assumption, not a forecast — results are measured and published either way.
  • Risk: max 8 open positions, $200/position, ±$0.05 target/stop, daily loss cap pauses entries.
  • Grading: open positions settle at the official YES/NO result; stats are broken out by strategy and by trade type so weak categories can be retired.
